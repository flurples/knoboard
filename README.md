# knoboard
a 40% with knobs in place of the alphas

<img width="4026" height="2263" alt="PXL_20211109_182431969" src="https://github.com/user-attachments/assets/47d3adc1-2c34-434f-a36e-47930990e1a3" />
sound test: https://youtu.be/37PdSRpsLzA

## you will need
- 1x top, bottom, & plate
- a lot of ec11 rotary encoders and knobs
- 8x m2 screws
- rubber feet of your choice
- a pro micro compatible controller board
- the patience to handwire & program everyting
